# Labs

One-off experiments behind the app's design decisions. Each script fits on older data, tests on newer data
it never saw, and prints the comparison; the results and what shipped (or didn't) are written up in
[docs/experiments.md](../docs/experiments.md). None of these run in the app or in the scheduled workflows.

Run from the repo root, e.g. `python labs/swap_quality_lab.py`.
